# 表格分析Agent测试问题与核对答案

> 此手册针对现已移除的表格分析Agent。Excel样例保留，当前聊天不再提供本手册描述的复杂分析能力。

生成日期：2026-10-19。全部为合成数据，不代表任何真实企业或客户。

## 使用方法

新建聊天，仅上传同目录中的“表格分析Agent测试数据.xlsx”，直接按下面顺序提问。不需要选择Agent或手动建立索引。只上传Excel；不要把本答案文件也上传，以免答案参与检索。

工作簿只有一个Sheet“销售明细”，36条明细、9列。每条记录是一笔独立销售订单，订单号唯一；12个客户各有3笔订单。单价、销售额的单位为人民币元，数量为件，销售额=数量×单价。日期范围2026-01-01至2026-03-24。客户编号001至012是文本标识符，应保留前导零。

原始数据没有空值、重复整行、退货、汇总行、公式或故意错误，适合先验证正常计算。这里没有业务制度、返点比例、成本或利润数据；不应自行编造这些信息。

## 连续追问：建议在同一个聊天中按顺序进行

| 顺序 | 可直接复制的问题 | 核对答案 |
|---|---|---|

| 2 | 销售额合计、平均值、最大值和最小值分别是多少？ | 合计222000元；平均6166.666…元，保留两位小数为6166.67；最大18000；最小1000。平均值分母是36笔订单。 |
| 3 | 只看华东地区，其他指标保持不变。 | 9笔，合计22200，平均2466.666…（2466.67），最大4500，最小1000。 |
| 4 | 在刚才华东范围内，只按产品统计销售额合计。 | 产品A=3700，产品B=7400，产品C=11100。应继续保留华东条件。 |
| 5 | 取消地区限制，按产品统计销售额合计，从高到低列出前两名。 | 产品C=111000；产品B=74000。应取消华东条件。 |
| 6 | 重新使用整张表的全部记录，按地区汇总销售额，并计算各地区占总销售额的比例。 | 华东22200/10%；华南44400/20%；华北66600/30%；华西88800/40%；分母222000。 |
| 7 | 使用整张表全部记录，按自然月统计销售额，并计算月度环比。 | 2026-01=60000；2026-02=72000、环比20%；2026-03=90000、环比25%。1月无基期，应标为不可计算，不能补成0%。 |

## 来源与显示核验

点击结果卡片“查看计算来源”，检查筛选后的记录数量与原始Excel行是否一致。未筛选时Excel第2至37行对应36笔订单；客户编号001/002等不能变成1/2。

数值显示允许合理四舍五入；金额单位统一为元。排序并列时顺序可不同，记录和数值应一致。若提出跨表合并、预测或绘图，当前版本应说明能力边界，不凭空生成执行结果。
