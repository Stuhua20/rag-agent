# Prompt 维护指南

运行时规则适用于任意已入库资料，不依赖某个客户、产品、领域缩写或数据集。具体案例只放在测试与回放材料中，不通过向模板追加个例修复回答。

## 写作与职责

- system：长期角色、证据边界、数据口径和表达规则。
- planner：问题补全、澄清、意图、子查询和后端已支持的执行参数。
- translator：保持检索含义与顺序的语言转换；标识符可原样保留。
- answer：本轮资料、后端证据状态、回答组织、缺失与冲突处理。
- no_source：无检索结果时的固定回复，不发送给模型。

规则应说明适用条件、所需行为和信息不足时的处理。使用通用的“对象、指标、时间、单位、统计口径”等概念，避免固定业务名称、缩写全称映射及特定年份或金额。中文回答、中英检索、JSON 枚举、Sheet 参数和输入区块名称属于当前产品协议，保留并与代码一致。

文字归纳使用 lookup，数值聚合使用 summary；comparison、ranking、trend 继续执行全量检索。缺失值不等于零，未检索到不等于不存在；局部可答时标明缺失字段，完整统计不能以局部数据替代。冲突应说明适用范围，不按相关度裁决。

模型不计算派生数值。已支持的确定性表格计算由代码直接返回，保持原有路径。后端证据报告说明基础覆盖状态，不自动证明每个字段或结论成立。未知覆盖状态不能写成已完成全量检查。

## 模板与执行契约

新增或变更变量须同步 `prompts/README.md`、模板组装和在线保存校验。答案模板保留原问题、补全问题和证据报告的独立区块。显式用户过滤优先于模型建议，模型给出的 Sheet 必须存在于可用元数据。翻译仍校验数量和目标语言，对原样保留的独立标识符允许缺少目标语言文字。

在线保存会清除模板缓存；直接编辑磁盘模板需重启服务或在线保存以失效缓存。本次同时调整了后端代码，已有服务进程需重启后使用完整的新契约。

## 回放检查

| 场景 | 预期 |
| --- | --- |
| 完整问题、明确历史追问、歧义追问 | 原话保留；仅明确条件可继承，歧义时澄清 |
| 内容解释与数值统计 | 不因出现归纳用词就触发数值计算 |
| 多对象、多字段且部分缺失 | 正常回答已知部分，缺失不填零 |
| 同一口径出现冲突 | 展示差异，不按检索顺序选答案 |
| 不同对象、期间、单位或指标的数字 | 不串用、不补算、不自行换算 |
| 完整统计、部分记录、覆盖状态未知 | 不宣称部分数据支持完整结论 |
| 不同领域缩写、编号及普通句子 | 不补全缩写背景，保持翻译对齐 |
| 显式范围与模型过滤建议冲突 | 用户范围优先，不接受未知 Sheet |
| 普通与流式回答 | 接收同一证据契约，最终结果仍经过核验 |

`backend/tests/test_prompt_contracts.py` 验证变量保存、缓存失效、过滤、翻译和两个回答入口的参数传递，使用临时数据和模拟模型。上述语义回放需要另用真实模型评测；离线通过不代表已证明模型的理解、翻译或归纳准确率。
