# 文件详情弹窗

在文件库点击「查看」打开独立弹窗，默认显示「内容预览」，也可切换「文件信息」。已有文件直接可用，无需重新上传。

## 文件结构

| 文件 | 职责 |
| --- | --- |
| `frontend/src/components/DocumentPreviewDialog.tsx` | 弹窗开关、页签、详情请求、分页、错误重试、键盘与焦点管理 |
| `frontend/src/components/SheetPreview.tsx` | 展示工作表或页面/章节信息、解析提示及当前页内容 |
| `frontend/src/styles/document-preview.css` | 弹窗布局、滚动区域、响应式及焦点样式 |
| `frontend/src/api/documents.ts` | 文件详情、工作表及内容分页请求，支持 AbortSignal |
| `frontend/src/pages/DocumentsPage.tsx` | 维护当前查看的文件，与列表搜索及管理选择衔接 |
| `frontend/src/main.tsx` | 加载独立弹窗样式 |

后端沿用现有详情、工作表及内容分页接口，没有新增接口或调整数据格式。

## 交互规则

- 每次打开从「内容预览」第 1 页开始；每页 50 段，可通过上一页、下一页浏览全部解析内容。
- 内容区独立滚动，标题、页签及分页操作保持可见；手机上使用接近全屏的布局。
- 工作表或页面/章节概况可展开，解析内容逐段展示；解析警告与处理失败原因在弹窗内显示。
- 「文件信息」包含名称、类型、来源路径、状态、上传及更新时间、解析数量等。后端历史时间为没有时区后缀的 UTC，显示时明确转换为北京时间。
- 请求失败显示重试入口；关闭或翻页时取消旧请求，并忽略已经失效的响应，防止旧内容覆盖新文件。
- 支持关闭按钮、Esc、点击遮罩关闭；页签支持左右方向键、Home 和 End，Tab 焦点保持在弹窗内。
- 关闭后恢复触发按钮焦点，保留文件库搜索条件、勾选及列表位置。

展示内容来自后端解析结果，PDF、Word、表格的原始排版和图片不属于本次预览范围。

## 验证

- 前端生产构建、4 项上传队列测试及差异格式检查通过。
- 7 组详情浏览器检查通过：真实 130 段 CSV 三页导航、DOCX/PDF 正文及警告、信息与北京时间、键盘与焦点恢复、加载失败重试、旧请求隔离、处理失败文件、桌面与手机布局。
- 7 组批量管理浏览器回归通过：筛选选择、删除确认取消、部分失败重试、串行锁定、原文件及索引清理、单文件删除等。
- 浏览器使用现有 Edge 和 Playwright，服务及资料位于 `/tmp/distributor-preview-qa`，不操作正式文件库。截图与详情结果位于其 `evidence` 目录。
