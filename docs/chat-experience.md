# 聊天页使用体验

## 欢迎页

无消息的聊天展示独立欢迎界面，介绍自然语言检索和来源证据，不添加示例问题或将欢迎语作为可复制的助手回答。历史记录加载和加载失败分别显示状态信息。

## 输入与草稿

- Enter 发送，Shift + Enter 换行；输入法组词时回车不发送。
- 提交后立即清空输入框，生成期间允许编辑下一条问题，发送按钮在当前回答结束前禁用，不自动排队发送。
- 首次回答结束更新聊天地址时保留组件实例，避免丢失正在编辑的草稿。
- 发送失败且用户未再编辑时恢复原问题；已有新编辑时保留新草稿。
- 文本框按内容和可用宽度调整高度，超过最大高度后在框内滚动。

## 当前文档范围

指定文档模式在输入框上方展示文件名标签，长名称省略并保留完整名称提示。点击可查看已有文件详情；通过“选择文档”调整范围。

文件名读取失败时保留当前范围并提供重试；缺失或未入库文档标记为不可用，点击进入范围调整。标签区域限制高度，避免大量文件挤占输入区域。全部文档模式不枚举文件。

## 回到底部

消息列表距离底部超过 80px 时显示“回到底部”。阅读历史消息时新回答不强制改变阅读位置，点击按钮回到最新消息并恢复跟随。滚动只作用于消息区域；减少动态效果设置下直接定位到底部。

## 验证

- TypeScript 与 Vite 生产构建。
- Playwright + 本机 Edge，1440×1000 和 390×844；接口使用模拟数据，不调用模型或改动真实聊天与文件。
- 验证欢迎界面、快捷键、输入法回车、生成中编辑与防重复发送、首次/已有聊天草稿保留、失败恢复及新草稿保护。
- 验证文档标签/预览/焦点恢复、长名称、不可用文档、名称加载失败重试和切回全部文档。
- 验证历史滚动按钮、不打断阅读、窄屏布局和多行输入。
