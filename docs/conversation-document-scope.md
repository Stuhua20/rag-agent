# 会话文档检索范围

聊天输入框上方的“选择文档”只修改当前会话的后续检索范围。默认“全部已入库文档”；“指定文档”至少需要一个已入库文档，支持按文件名/路径搜索、全选当前结果、清空及取消。

## 会话与消息

会话增加 `document_scope: { mode: "all" | "selected", document_ids: string[] }` 和 `scope_revision`。ID 去重排序后比较，重复应用同一集合不增加版本。旧会话未保存字段时按 all / 0 读取，无需迁移。

新会话的选择先保留在页面，首次提问时创建带初始范围的会话；已有会话的选择立即保存到后端。刷新和切换回来恢复选择，点击新聊天恢复默认范围。全部模式自动包含新入库文件；指定模式不会自动增加文件。

每条新消息保存本轮范围及版本快照。范围改变后只取当前版本消息构建查询规划与回答上下文；旧消息仍显示，并有范围变化分隔提示。切回以前的文件集合也开始一个新版本。

## API

- `GET /api/conversations/{id}`：会话详情，包含标准化范围、版本及 `invalid_document_ids`。
- `POST /api/conversations`：兼容原 title，支持可选 `document_scope`。
- `PATCH /api/conversations/{id}`：接收 `document_scope` 和 `expected_scope_revision`。版本冲突返回 409，修改采用原子条件更新。
- `POST /api/chat`、`POST /api/chat/stream`：可传 `expected_scope_revision`。省略时仍使用会话保存的范围，不会变成全库。

范围失效、版本冲突在发送 SSE 响应头前返回 HTTP 409，不写入该轮消息。前端刷新会话范围，用户核对后重试。空选择和模式错误返回 422；会话不存在返回 404。

## 范围约束

范围 ID 来自已验证的会话设置，与模型 Query Plan 分开。元数据只来自选中文档；检索在评分、排序和 top-k 前过滤；来源引用回填也过滤。工作表筛选在文档范围内继续生效，模型不能扩大范围。

所选范围无匹配时返回“所选文档中未找到明确依据。”；文件失效时提示用户移除或重新选择，不回退全库。流式正文、最终答案校验和已存在的原话/补全问题分离均保留。

同一轮固定发送时的范围快照。其他标签页随后修改范围不改变这一轮；下一轮的版本校验会提示冲突。前端切换会话会取消旧请求，并阻止其更新新会话界面。

JSON 存储仍使用单服务进程。增删改读写由进程内 RLock 保护，范围保存使用版本条件更新；没有新增数据库、依赖或全库数据迁移。

## 验证

- 后端 `tests/test_document_scope.py`：会话持久化、同名文件 ID、空/失效选择、旧会话、相同集合、并发更新、普通/多查询/全量检索、元数据、表格计算、引用回填、模型片段、无匹配不扩大范围、同步/流式错误前置、历史版本及生成中范围快照。
- 使用临时 DATA_DIR / STORAGE_DIR 和 mock 模型进行测试，不写真实文档库或访问真实模型 API。
- 浏览器采用现有 Playwright + 无头 Edge，验证 1440×1000 与 390×844 布局、弹窗键盘和实际 SSE。临时资料分别为 100、900，仅选一个分别回答 100、900，同时选择回答 1000。
- 未重启用户正在运行的服务；后端未启用自动重载时需重启后生效。

最终结果（2026-10-15）：54 项后端测试、4 项前端测试、答案质量/P0/冒烟自检、生产构建及差异检查通过。12 组浏览器检查通过，涵盖真实 SSE、部分正文提前可见、范围保存与恢复、异常重试、同名文件、上下文切换和移动布局。浏览器仅记录既有 favicon.ico 404 及主动注入的预期错误响应。
